## About The Project

**UIT Waifu** is an AI-powered virtual assistant designed for students at the **University of Information Technology**.

The project combines a friendly waifu-style chatbot experience with practical academic tools such as study support, code explanation, document summarization, schedule planning, reminders, and university-related assistance.

UIT Waifu is not just a chatbot. The goal is to build a smart student companion that helps users learn faster, manage deadlines, understand difficult subjects, and organize university life more efficiently.

The assistant is designed to be friendly, supportive, and useful while still focusing on real academic productivity.

---

## Why UIT Waifu?

University students often have to handle many things at the same time:

- Lectures
- Assignments
- Exams
- Project deadlines
- Class schedules
- Course documents
- University announcements
- Personal tasks
- Group projects
- Study plans

UIT Waifu aims to reduce that pressure by acting as a helpful AI companion. Instead of switching between many different tools, students can interact with one assistant to ask questions, summarize materials, debug code, manage reminders, and plan their studies.

The project focuses on three main ideas:

1. **Academic support**  
   Help students understand programming, AI, data science, mathematics, and university subjects.

2. **Productivity support**  
   Help students manage tasks, deadlines, reminders, and study schedules.

3. **Friendly experience**  
   Make the assistant feel more engaging and enjoyable than a normal chatbot.
